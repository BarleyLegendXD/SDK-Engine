# SDK-Engine
Интересный и довольно мощный 2D движок на питоне

SDK-Engine v1.2.3 — это по сути готовый каркас для твоих игр на Python, который берет на себя всю грязную работу с отрисовкой, физикой и ресурсами. Всё взаимодействие происходит через систему модов, где ты просто подписываешься на нужные события и используешь встроенные инструменты для создания логики.  Управление и ввод (через s["input"])**key(code)**: Проверяет, зажата ли клавиша в текущий момент. Используется для постоянных действий, например, чтобы персонаж шел, пока ты держишь "W".
**key_down(code)**: Срабатывает только один раз в момент нажатия кнопки. Идеально подходит для прыжка или выстрела, чтобы они не повторялись бесконечно при зажатии.
**mouse_down(button)**: То же самое, что и нажатие клавиши, только для мыши (0 — левая кнопка, 2 — правая).
**world_mouse_pos**: Дает координаты курсора сразу в игровом мире, учитывая, куда отъехала камера. Тебе не нужно ничего вычитать вручную, просто используй это для прицеливания или кликов по объектам.
Мир и объекты (через s["objects"])**create(x, y, w, h, layer, physics, body_type)**: Главная команда для создания чего угодно. Параметр `physics=True` включает гравитацию, а `body_type` определяет, будет ли объект падать (DYNAMIC) или стоять на месте как стена (KINEMATIC).
**group(name, *objs)**: Объединяет объекты в группу. Удобно, когда нужно применить действие сразу ко всем врагам или пулям одной командой.
**obj.set(pos=(x, y), color=(r, g, b))**: Позволяет мгновенно поменять любые настройки объекта (позицию, размер, цвет) прямо в коде.
**obj.anim(attr, end_val, duration)**: Запускает плавную анимацию. Можно заставить объект плавно менять позицию, размер или прозрачность за указанное количество секунд.
**obj.is_clicked(input, button, camera.offset)**: Проверяет, кликнул ли игрок именно по этому объекту в мире. Сама учитывает смещение камеры.
Камера и визуал (через s["camera"] и s["resources"])**camera.follow(target)**: Приказывает камере плавно следовать за игроком или любым другим объектом.
**camera.shake(amp, duration)**: Включает тряску экрана. Отлично подходит для эффектов взрывов или ударов.
**camera.sway(amp, speed)**: Создает эффект легкого покачивания камеры, как будто герой дышит.
**resources.load_img(name, path)**: Загружает картинку, чтобы потом повесить ее на объект через `texture_name`.
**resources.load_gif_folder(name, path)**: Берет папку с кадрами и превращает их в анимацию спрайта.
Система событий и движок (через engine)**on(name, func, priority)**: Позволяет «вклиниться» в работу движка. Ты вешаешь свою функцию на `update` (обработка логики) или `draw` (отрисовка), и движок будет вызывать её сам.
**audio["play"](name)**: Запускает звук, который ты загрузил ранее.
**audio["generate"](name, freq, duration)**: Создает звук программно (писк определенной частоты). Полезно для ретро-эффектов без использования файлов.
**log(text, color)**: Выводит твой текст в окно консоли на экране и записывает его в файл лога в папку `cache`.
